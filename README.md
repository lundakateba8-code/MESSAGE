# 🚀 lundakateba8-code

Projet full-stack avec backend et frontend séparés.

## 📁 Dossiers

- `backend/` : code du serveur (API, base de données, logique métier)
- `frontend/` : interface utilisateur (HTML/CSS/JS, React, Vue, etc.)

## 🔧 Installation

### Backend

```bash
cd backend
npm install   # ou pip install -r requirements.txt (selon ton langage)
npm start     # ou python app.py
